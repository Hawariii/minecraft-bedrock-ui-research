# Minecraft Bedrock UI Research

> Community-driven documentation and reverse engineering of Minecraft Bedrock Edition JSON UI.

This repository aims to build the most comprehensive open reference for Minecraft Bedrock Edition's JSON UI system. It documents known `button_id`s, bindings, collections, screens, controls, properties, events, animations, textures, variables, and other hardcoded UI behavior discovered through official resources, community research, and reverse engineering.

Whether you're creating a Resource Pack, Add-on, UI Pack, or simply exploring how Bedrock's interface works, this project is designed to serve as a reliable reference.

---

## Features

- Comprehensive `button_id` database
- Binding documentation
- Collection reference
- Screen hierarchy reference
- Hardcoded UI controls
- Supported UI properties
- Animation reference
- UI events
- Texture reference
- UI sound mapping
- Screen variables
- Reverse engineering notes
- Version compatibility tracking
- Practical implementation examples
